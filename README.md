# AI by Design - Hands-on GenAI Lab

A hands-on lab guide for exploring Generative AI concepts including LLMs, embeddings, vector databases, RAG pipelines, fine-tuning, and multimodal AI.

## Lab Modules

| Module | Topic |
|--------|-------|
| Task 1 | Getting Started with LLMs |
| Task 2 | Introduction to AI |
| Task 3 | Tokenization & Embeddings |
| Task 4 | Vector Databases |
| Task 5 | RAG Pipeline |
| Task 6 | Document Processing |
| Task 7 | Dashboard & Visualization |
| Task 8 | Fine-Tuning Models |
| Task 9 | Multimodal AI |

## Quick Start

```bash
# Install dependencies
pip install -r requirements.txt

# Serve locally
mkdocs serve

# Deploy to GitHub Pages
mkdocs gh-deploy
```
